# Настройки `World.json` (aaemu-game)

Этот файл описывает настройки из `Configurations/World.json` в каталоге
приложения игрового сервера (`rust/crates/aaemu-game/app/` при запуске из
исходников, `AAEmu.Game/` в опубликованной сборке, `.server_files/AAEmu.Game/`
в Docker).

## Где настраивать

- **Файл**: `rust/crates/aaemu-game/app/Configurations/World.json`
- **Локальное переопределение**: добавьте раздел `World` в `Config.Local.json`
  рядом с `Config.json` (он загружается после `Configurations/*.json`) или
  используйте переменные окружения, например `World__ExpRate=2`
- **Раздел**: `World`

Пример:

```json
{
  "World": {
    "MOTD": "Welcome to AAEmu!",
    "TargetPhysicsTps": 25.0
  }
}
```

## Параметры

### `MOTD`
- **Тип**: `string`
- **Описание**: сообщение дня (показывается игроку в чат при входе).

### `LogoutMessage`
- **Тип**: `string`
- **Описание**: сообщение при выходе из игры.

### `AutoSaveInterval`
- **Тип**: `number`
- **Описание**: интервал автосейва в минутах.

### `ExpRate`
- **Тип**: `number`
- **Описание**: серверный множитель опыта.

### `HonorRate`
- **Тип**: `number`
- **Описание**: серверный множитель чести.

### `VocationRate`
- **Тип**: `number`
- **Описание**: серверный множитель ремесленных/проф. очков.

### `LootRate`
- **Тип**: `number`
- **Описание**: множитель выпадения лута (не все типы лута зависят от него).

### `GoldLootMultiplier`
- **Тип**: `number`
- **Описание**: множитель золота из лута.

### `GrowthRate`
- **Тип**: `number`
- **Описание**: множитель скорости роста doodad-ов (шаги роста, не обычные таймеры).

### `DaysForTaxPayment`
- **Тип**: `number`
- **Описание**: сколько дней оплачивает одна “неделя” налога (по умолчанию 7).

### `IgnoreFallDamageAccessLevel`
- **Тип**: `number`
- **Описание**: минимальный access-level, при котором игнорируется урон от падения.

### `RadarGmAccessLevel`
- **Тип**: `number`
- **Описание**: минимальный эффективный access-level, при котором радар / телескоп показывает все объекты мира независимо от зарегистрированного радиуса (по умолчанию `100`; уменьшите, чтобы выдать GM-радиус большему числу аккаунтов).

### `GodMode`
- **Тип**: `boolean`
- **Описание**: если `true`, игроки не получают урон.

### `MoveGuardEnabled`
- **Тип**: `boolean`
- **Описание**: серверная защита движения (по умолчанию `true`). Каждая позиция, присланная клиентом (игрок пешком, свой маунт, управляемая наземная машина), проверяется по бюджету скорости юнита; слишком большой скачок отбрасывается, пишется в `audit_char_sus` (категория `Cheat`), а клиента возвращают на серверную позицию.

### `MoveGuardMaxSpeed`
- **Тип**: `number`
- **Описание**: допустимая средняя горизонтальная скорость игрока или маунта, м/с (по умолчанию `30.0`).

### `MoveGuardMaxUpSpeed`
- **Тип**: `number`
- **Описание**: допустимая средняя скорость подъёма, м/с (по умолчанию `30.0`); падение не ограничивается.

### `MoveGuardBurstSeconds`
- **Тип**: `number`
- **Описание**: сколько секунд скорости может накопиться в бюджете (лаги, рывки; по умолчанию `3.0`).

### `MoveGuardVehicleMaxSpeed`
- **Тип**: `number`
- **Описание**: допустимая скорость управляемой клиентом наземной машины, м/с (по умолчанию `45.0`).

### `MoveGuardExemptAccessLevel`
- **Тип**: `number`
- **Описание**: персонажи с таким access-level и выше не проверяются (по умолчанию `50`).

### `MoveGuardKickAfterViolations`
- **Тип**: `number`
- **Описание**: отключать игрока после стольких отклонённых ходов за `MoveGuardViolationWindowSeconds` (по умолчанию `0` = не отключать).

### `MoveGuardViolationWindowSeconds`
- **Тип**: `number`
- **Описание**: окно для `MoveGuardKickAfterViolations` (по умолчанию `60.0`).

### `GeoDataMode`
- **Тип**: `boolean`
- **Описание**: включает загрузку GeoData/NavMesh (используется для данжей и навигации).

### `PreLoadTerrain`
- **Тип**: `boolean`
- **Описание**: если `true`, подгружает террейн заранее (быстрее в рантайме, дольше старт, больше память).

### `MaxInstances`
- **Тип**: `number`
- **Описание**: максимальное количество инстансов (включая системные).

### `TargetPhysicsTps`
- **Тип**: `number`
- **Описание**: целевой TPS физики (тикрейт потока физики).

### `ActabilityRate`
- **Тип**: `number`
- **Описание**: серверный множитель actability points.

## Ветер для кораблей

### `WindModel`
- **Тип**: `string`
- **Где**: `World.WindModel`
- **Допустимые значения**:
  - **`Official`**: офф-лайк модель ветра.
    - ветер **не меняется** от времени суток;
    - бонус **+15%** к максимальной скорости даётся **только** при движении в пределах **±15°** от оси **Север↔Юг** (в обе стороны);
    - при выходе за порог бонус **пропадает**.
  - **`Realistic`**: “реалистичная” модель ветра.
    - направление ветра **плавно вращается** в течение суток (и применяется логика профилей парусов).

Примеры:

```json
{
  "World": {
    "WindModel": "Official"
  }
}
```

```json
{
  "World": {
    "WindModel": "Realistic"
  }
}
```

## Морская погода (морские события)

### `SeaWeatherModel`
- **Тип**: `string`
- **Где**: `World.SeaWeatherModel`
- **На что влияет**: только на поведение кораблей во время морских погодных doodad-ов (штормовое облако / водоворот). На **точки спавна** не влияет — они задаются спавнерами морской погоды (маркер-шаблон `2768`) в данных спавна мира.
- **Допустимые значения**:
  - **`Official`**: офф-лайк (по умолчанию).
    - остаётся **офф-лайк замедление** в шторме;
    - притягивание в водовороте (дрейф к активному водовороту по бафу) всё равно работает.
  - **`Realistic`**: продвинутая / более “живая”.
    - остаётся **офф-лайк замедление** в шторме;
    - дополнительно включает поведение корабля в шторме, когда активен штормовой баф:
      - **блокирует стрельбу** из корабельных **пушек** в шторме (гарпун не блокируется);
      - автоматически “зажигает” корабельные фонари (перед/зад) в шторме;
      - принудительно выставляет отображаемое клиентом время суток на **02:00**, пока активен штормовой баф.
    - притягивание в водовороте остаётся включено (как и при `Official`).

Примеры:

```json
{
  "World": {
    "SeaWeatherModel": "Official"
  }
}
```

```json
{
  "World": {
    "SeaWeatherModel": "Realistic"
  }
}
```
