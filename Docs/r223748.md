# ArcheAge 1.2.5.0 r223748

This branch targets the Steam r223748 client (2015-03-18). It includes native
Rust translation of the protocol previously verified through the local bridge.
Clients connect directly to the configured server address; no compatibility proxy
is required. Login and stream protocols retain their existing IDs.

## Server

Build/publish the usual Rust login and game binaries. This branch's game
`app/Config.json` sets `ClientRevision` to **223748**. Copy that setting to an
existing installation's `Config.Local.json` if it overrides configuration:

```json
{
  "ClientRevision": 223748
}
```

The default of the configuration *type* remains 208022 for existing embedders and
tests. Explicit `ClientRevision: 208022` preserves the old protocol. A listener
serves one revision; it does not negotiate revisions or support mixed clients on
one port. Values other than 208022 and 223748 are rejected.

Keep the server's **r208022 server compact database and world data**. Do not replace
it with the r223748 client database, which omits required server tables. Ordinary
SQL migration/setup instructions continue to apply. No account DB or credentials
are supplied in this branch or in the client bundle.

For a remote connection, configure the game's advertised public IPv4 address and
game/stream ports in the existing network/world-registration settings, following
[Networking](networking.md) and the existing login/game configuration files.
Expose login/game/stream TCP ports (defaults 1237/1239/1250); the internal login
link and databases stay private. Both login and game must share the same secret.
Entering a remote login IP in the launcher does not override an incorrectly
advertised loopback game address.

For example, in the **login** server's `Config.Local.json`, advertise your real
reachable server IPv4 instead of this documentation-only example address:

```json
{
  "Network": { "Host": "*", "Port": 1237 },
  "GameServers": [
    { "Id": 1, "Name": "AAEmu r223748", "Host": "192.0.2.10", "Port": 1239, "Hidden": false }
  ]
}
```

In the **game** server's override, use `ClientRevision: 223748`, bind
`Network.Host: "*"` on 1239 and `StreamNetwork.Host: "*"` on 1250. Retain your
existing database credentials and internal login link configuration.

## Client and launcher

`client/r223748/` contains the portable Windows launcher source. Copy `Play.cmd`,
`server.json`, `README.txt` and the `Launcher/` directory into the original client's
`ArcheAge` folder beside `bin32` and `game_pak`. Double-click `Play.cmd`, enter an
IPv4 address, login port, username and password, and select the world normally.
`server.json` supplies defaults; account passwords are not saved. The UI uses
Windows PowerShell 5.1 / .NET Framework and requires no .NET SDK or Steam session.

The launcher checks exact SHA256 hashes of archeage.exe, x2game.dll and
CryNetwork.dll. It supplies the Trion shared-memory login ticket and applies
signature-checked **in-memory** HackShield, no-browser and AAEmu no-crypto patches.
No client binary is modified on disk. A failed patch terminates only the process
created by that invocation. The DirectX June 2010 x86 helper DLLs can be bundled
side by side, or the Microsoft runtime can be installed separately.

For a complete local bundle from the matching original archive:

```powershell
powershell -NoProfile -File client\r223748\Build-ClientBundle.ps1 `
  -ClientArchive 'C:\Downloads\AA 1.2.5.0 - Trion - r223748 - 2015-03-18.7z' `
  -SevenZip 'C:\Tools\7zr.exe' `
  -DirectXDirectory 'C:\Tools\dxredist\x86' `
  -OutputDirectory 'C:\Bundles\AAEmu-r223748'
```

The builder copies the original archive, adds only launcher/runtime helper files,
checks archive integrity and writes SHA256SUMS.txt. It does not include saved
credentials, connection logs, private configuration, runtime dumps or server DBs.
Client archives and Microsoft helper binaries are local assets, never committed.

## Compatibility and verification

The socket adapter has **515 server-to-client and 244 client-to-server mappings**.
It adapts character requests, Trion settings, spam delay, actor collision option,
mail totals, chat hyperlinks, and the four types emitted by the current server's
compressed plot/damage/healing/cooldown batches. Unknown IDs are withheld rather
than dispatched to an unrelated handler. Malformed/truncated frames fail closed.

Tests cover the distinct restriction/select requests, captured movement with both
optional-header forms, character-state suffix preservation, eight mail counts,
chat suffix preservation and captured compressed plot/damage batches. They run in
`cargo test -p aaemu-game net::r223748`. Socket-boundary integration preserves
broadcasts and delayed writes; r208022's internal packet definitions stay intact.

The original bridge was played for about 30 minutes: login, Cosmic's world entry,
movement, plain chat, NPC quests, mining, combat and XP. That establishes these
paths, not complete gameplay parity. Nonempty item hyperlinks, other embedded
actor movements and exact mail-total semantics remain unaudited. The compatibility
layer derives totals from the old protocol's available counts. New r223748-only
features and unmapped outgoing requests need further reversing.
